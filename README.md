## How I Stay Consistent

- Fixed daily slots, same time and same place.
- Minimum version on bad days: 2 problems and 30 minutes of study. Never miss two days in a row.
- Every mistake goes into a notebook and is revised after 1, 3, 7 and 30 days.
- Weekly review on Sunday, monthly review at the end of each month.
- Daily commits with clear messages, for example `Day 12: 2D arrays practice`.
